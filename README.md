# Accountrix Pro

Chtěl bych vytvořit účetní aplikaci, která bude umět: Vytvořit a uložit fakturu, dále pak vyhledat, případně vymazat, upravit a přidat fakturu. Chtěl bych, aby na faktuře bylo vidět vše potřebné (Jméno klienta, adresa, IČO/DIČ, tel. číslo, email, plátce/neplátce DPH,m datumy, vypsaný typ služby/výrobku/zboží, cena bez dph, vyčíslené dph, cena celkem a další důležité faktory, které faktura potřebuje). Aplikace by měla mít moderní styl, ideálně barvy (bíla, černá, modrá) Název by měl být Accountrix.
